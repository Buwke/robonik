# Робоник

«Робоник» - образовательный набор для знакомства с робототехникой, электроникой и программированием. В проект входят учебный манипулятор на Arduino и редактор команд «Робоник Студия». В редакторе можно составить последовательность движений приводов и команд для светодиода, проверить её в деморежиме и выполнить на подключённом манипуляторе.

## Запуск «Робоник Студии»

Нужен Python 3 с Tkinter. Для деморежима достаточно запустить приложение из корня репозитория.

```bash
python3 app/studio.py
```

На Windows используйте `py app/studio.py`. На macOS также можно запустить `zsh app/launch.command`.

При первом запуске откроется пример программы. Нажмите «Запустить», чтобы увидеть, в каком порядке выполняются команды. Свои программы можно сохранять и открывать в формате `.robonik`.

## Подключение Arduino

Установите зависимости командой `python3 -m pip install -r app/requirements.txt` (на Windows — `py -m pip install -r app/requirements.txt`). Подключите Arduino Uno с прошивкой Firmata. В приложении нажмите «Подключить Arduino», выберите порт и укажите пины и рабочие углы приводов по фактической сборке.
